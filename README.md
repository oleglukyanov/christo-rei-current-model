# Garajau current model: interactive viewer

Interactive map of a modelled tidal current around the Cristo Rei headland (Garajau, Madeira), with fastest swim routes
for different stream strengths, swimmer speeds and distances from the rock.

**Model result only. It is not validated against measured currents at Garajau, it has no waves or wind, and the seabed
near the rock is assumed. It is not safety advice.**

`index.html` is a single self-contained file (no server, no external libraries).

Data: coastline © OpenStreetMap contributors (ODbL); ambient currents from COAWST/ROMS output by Faria, Vieira & Caldeira (2019),
[doi:10.1594/PANGAEA.898870](https://doi.org/10.1594/PANGAEA.898870) (CC BY 4.0); seabed depth calibrated with EMODnet Bathymetry.
